Pendahuluan

Website ini berisi tutorial lengkap merangkai kabel LAN tipe crossover menggunakan kabel UTP, konektor RJ45, tang crimping, dan LAN tester. Selain itu dijelaskan cara menghubungkan dua laptop menggunakan kabel LAN serta cara melakukan sharing file melalui jaringan LAN.

Alat dan Bahan

RJ45

Konektor untuk ujung kabel LAN.

LAN Tester

Mengecek kabel sudah benar atau belum.

Tang Crimping

Menjepit konektor RJ45 pada kabel.

Kabel UTP

Media penghantar data dalam jaringan LAN.

Langkah Merangkai Kabel LAN

1

Siapkan alat dan bahan

Siapkan kabel UTP, dua konektor RJ45, tang crimping, dan LAN tester.

2

Kupas kabel UTP

Kupas bagian luar kabel sekitar 2 cm menggunakan tang crimping.

3

Susun warna kabel

Susun ujung pertama menggunakan standar T568A dan ujung kedua menggunakan T568B.

4

Masukkan ke konektor RJ45

Pastikan semua kabel masuk hingga ujung konektor.

5

Jepit konektor

Gunakan tang crimping hingga konektor terkunci pada kabel.

6

Uji menggunakan LAN Tester

Pastikan lampu indikator menyala berurutan sebagai tanda kabel berfungsi.

Menghubungkan 2 Laptop Menggunakan Kabel LAN

  1. Hubungkan kedua laptop menggunakan kabel LAN crossover.
  2. Buka Network and Sharing Center pada kedua laptop.
  3. Pilih Ethernet kemudian Properties.
  4. Pilih Internet Protocol Version 4 (TCP/IPv4).
  5. Laptop 1 IP : 192.168.10.1 | Subnet Mask : 255.255.255.0
  6. Laptop 2 IP : 192.168.10.2 | Subnet Mask : 255.255.255.0
  7. Simpan pengaturan dan lakukan ping untuk memastikan kedua laptop saling terhubung.

Cara Sharing File Melalui Kabel LAN

  1. Pastikan kedua laptop sudah terhubung.
  2. Pilih folder yang akan dibagikan.
  3. Klik kanan → Properties → Sharing.
  4. Pilih Share kemudian tambahkan Everyone.
  5. Berikan izin Read/Write jika diperlukan.
  6. Buka File Explorer pada laptop kedua.
  7. Ketik alamat \\192.168.10.1 pada Address Bar.
  8. Folder yang dibagikan akan muncul dan file dapat disalin.

Kesimpulan

Merangkai kabel LAN tipe crossover dilakukan dengan menyusun warna kabel menggunakan standar T568A dan T568B, kemudian memasang konektor RJ45 menggunakan tang crimping dan menguji kabel menggunakan LAN tester. Setelah kabel berfungsi, dua laptop dapat dihubungkan melalui kabel LAN, diberikan alamat IP yang berbeda namun berada dalam satu jaringan, kemudian melakukan sharing file melalui fitur Network Sharing pada Windows.
