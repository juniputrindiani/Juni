Modul Teori 1

1. Pendahuluan Kabel LAN / Ethernet

Pengertian dasar, fungsi utama, kategori kecepatan, dan struktur fisik kabel Local Area Network.

Apa itu Kabel LAN / Ethernet?

Kabel LAN (Local Area Network) atau kabel Ethernet adalah media transmisi data fisik berupa kumpulan kawat tembaga terpilin yang berfungsi untuk menghubungkan beberapa perangkat komputer, laptop, router, maupun switch dalam jaringan area lokal.

Kabel LAN memberikan stabilitas koneksi yang unggul, latensi (ping) yang sangat rendah, serta bebas dari gangguan interferensi sinyal Wi-Fi. Hal ini menjadikannya pilihan utama untuk transmisi data cepat antar perangkat.

UTP

Unshielded Twisted Pair

Kabel tanpa pelindung foil tambahan, sangat lentur, ekonomis, dan standar penggunaan indoor.

STP

Shielded Twisted Pair

Dilengkapi pembungkus foil individual pada tiap pasang kawat untuk cegah interferensi.

FTP

Foiled Twisted Pair

Menggunakan satu lapisan pelindung foil utama yang membungkus seluruh pasangan kawat.

Kategori Kecepatan (Cat)

  • Cat 5e

    Transmisi s/d 1 Gbps (100 MHz)

    Standar

  • Cat 6

    Transmisi s/d 10 Gbps (250 MHz)

    Rekomendasi

  • Cat 7

    Transmisi s/d 10 Gbps (600 MHz)

    Ultra Speed
Modul Teori 2

2. Alat-Alat & Bahan Crimp Kabel LAN

Peralatan wajib yang digunakan dalam perakitan dan pengujian kabel LAN.

Kabel UTP (Cat5e / Cat6)

Kabel dengan 8 kawat tembaga terpilin (4 pasang warna) sebagai media perambat pulsa sinyal data.

Konektor RJ-45

Konektor plastik bening 8 pin yang akan dikunci pada ujung kabel untuk dipasang pada port LAN laptop.

Tang Crimp (Crimping Tool)

Tang presisi memotong kabel, mengupas kulit kabel, dan menekan pin tembaga RJ-45 hingga terkunci sempurna.

LAN Cable Tester

Alat indikator lampu LED (1 s/d 8) untuk memastikan tidak ada kawat tembaga yang terputus atau tertukar.

Catatan Perbedaan Kabel Cross vs Straight:

• Kabel Cross (Crossover): Memiliki susunan berbeda di kedua ujungnya (Ujung 1: T568A & Ujung 2: T568B). Digunakan khusus untuk menghubungkan 2 perangkat sejenis secara langsung tanpa hub/switch (contoh: Laptop A ke Laptop B).
• Kabel Straight-Through: Memiliki susunan warna persis sama di kedua ujungnya (T568B ke T568B). Digunakan untuk menghubungkan perangkat berbeda (Laptop ke Switch / Router).

Modul Praktikum 2

6. Menghubungkan 2 Laptop via Kabel LAN

Langkah konfigurasi fisik dan pengisian Alamat IP Statis IPv4 pada jaringan lokal.

Langkah 1: Penyambungan Fisik

  • Hubungkan ujung A kabel LAN (Tipe Cross) ke Port Ethernet pada Laptop A.
  • Hubungkan ujung B kabel LAN ke Port Ethernet pada Laptop B.
  • Pastikan indikator lampu LED pada Ethernet Card menyala berkedip.

Langkah 2: Konfigurasi Static IP (IPv4)

Buka Control Panel > Network and Internet > Network and Sharing Center > Change Adapter Settings > Properties IPv4.

Parameter Configuration Laptop A (Pengirim) Laptop B (Penerima)
IP Address 192.168.1.1 192.168.1.2
Subnet Mask 255.255.255.0 255.255.255.0
Default Gateway Dikosongkan Dikosongkan
Modul Praktikum 3

7. Pengecekan Keterhubungan (Uji Ping CMD)

Menguji sinyal respon transmisi antar laptop menggunakan Command Prompt (CMD) interaktif.

Penjelasan Uji Ping

Perintah ping mengirimkan paket ICMP Echo dari Laptop A ke Laptop B. Jika balasan menunjukkan Reply from 192.168.1.2..., jaringan fisik telah sukses!

Jika Muncul Request Timed Out (RTO):

Matikan sementara Windows Defender Firewall pada kedua laptop untuk profil jaringan private.

Simulasi Administrator: Command Prompt (Laptop A)

Ketik ping 192.168.1.2 atau ipconfig di bawah lalu tekan Enter:

C:\Users\Juni>
Modul Praktikum 4

8. Cara Transfer File / Folder Antar Laptop

Mengirim dan membagikan data berkali-kali lipat lebih cepat tanpa memerlukan jaringan internet.

1

Atur Folder Sharing

Klik kanan folder pada Laptop A > Properties > tab Sharing > klik tombol Advanced Sharing... atau Share....

2

Atur Permisi (Everyone)

Tambahkan user Everyone pada daftar share, ubah Permission level menjadi Read/Write, lalu klik Apply.

3

Akses Dari Laptop B

Pada Laptop B, tekan Win + R (Run), ketik path jaringan \\192.168.1.1 dan tekan Enter!
